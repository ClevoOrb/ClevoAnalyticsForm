# Clevo Analytics Form

A React web app for creating and filling dynamic health questionnaires. Admins upload an Excel file of questions, which becomes a themed, multi-section form stored in Supabase. Users log in with a Clevo code and mobile number, fill sections with gamified rewards (coins, streaks, badges), and view an LLM-generated health assessment or Ayurvedic constitution report.

**Live:** https://clevo-analytics-form-five.vercel.app/analytic-forms

## Tech Stack

React 18 · Vite · Tailwind CSS · React Router 6 · Supabase (PostgreSQL) · Recharts · Framer Motion · SheetJS
